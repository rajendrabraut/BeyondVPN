**Pre-release.** First public build of Beyond VPN: WireGuard VPN with a FastAPI control plane, a Rust gateway and agent, and clients for Windows/macOS/Linux, Android, iOS (source), the web and browsers.

> Not yet production-certified: no real-server deployment test, unsigned binaries and no external pentest yet (see "Known gaps"). Use for pilots and evaluation.

## What's in it

- **Control plane** (Python/FastAPI): accounts, TOTP MFA, **OIDC single sign-on** (Entra ID, Google, Okta, Keycloak), devices, WireGuard provisioning, usage and DNS/web activity logging with consent, admin console API, hash-chained audit log, **Alembic migrations**, **Redis-shared rate limits**.
- **Gateway** (Rust): kernel WireGuard peer sync, usage metering, filtering DNS resolver with blocklists, authenticated HTTPS proxy for the browser extension, **multi-hop** uplinks, **stealth mode** (WireGuard inside TLS on 443).
- **Agent** (Rust): CLI + local API for the desktop app, kill switch, split tunnelling, stealth, multi-hop, **native Windows service**, DPAPI-protected secrets.
- **Clients**: Electron desktop app, Android app, web portal (with SSO), Chrome/Edge/Firefox extension, iOS app source (SwiftUI + NetworkExtension, build on a Mac).

## Upgrading / first install

- Control plane applies database migrations at start (`beyond-cp migrate` does it on demand). Databases created by earlier development builds are stamped, not re-created.
- Deployment steps: `docs/DEPLOY_RUNBOOK.md`; SSO: `docs/SSO.md`.

## Verified for this release

- CI on Linux, Windows and macOS: Rust clippy + tests, control-plane tests (52), web/extension/desktop tests, Android unit tests + build, cross-language end-to-end test.
- On Windows 11: Windows service install/run/uninstall, ACLs, DPAPI; WireGuard-NT tunnel through a gateway running in a local Linux VM (handshake, DNS, blocklist, activity log).
- Dependency audits: Python (pip-audit) and npm production + dev dependencies clean; Rust (cargo audit) recorded in the release checklist.

## Known gaps (not production-ready yet)

1. No deployment on real Linux servers yet (runbook ready: `docs/DEPLOY_RUNBOOK.md`).
2. Binaries are not code-signed; Windows SmartScreen will warn. No one-click desktop installer yet.
3. Android APK is debug-signed (no Play Store key yet).
4. iOS app is source only (not compiled).
5. No external penetration test yet.
6. Activity logging of visited domains is personal data — get user consent (the app does at sign-up) and follow CERT-In / DPDP rules before going live (`GUARDRAILS.md` §3).
